# BIPA 学习区

BIPA = Bahasa Indonesia bagi Penutur Asing，即面向外国人的印尼语教学体系。

这个目录用于后续从“生活口语”转入系统学习。

计划结构：

```text
bipa/
├── README.md
├── a1/
├── a2/
├── b1/
├── b2/
└── vocabulary/
```

建议学习路线：

1. A1：基础自我介绍、家庭、时间、地点、简单日常事务
2. A2：更完整的生活交流、描述、过去经历、计划与请求
3. B1：较系统的语法、词缀、阅读、较正式表达
4. B2：复杂表达、工作交流、长文本、正式写作与讨论

在进入 BIPA 前，先把 `../lessons/` 中的 1–4 章生活口语练到能快速反应。
