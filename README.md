# Indonesian Learning + BIPA

这是一个面向中文母语者的印尼语学习仓库。

当前学习分为两部分：

1. `lessons/`：生活交流型印尼语，先解决“能听、能说、能在真实场景中使用”。
2. `bipa/`：后续系统学习 BIPA（Bahasa Indonesia bagi Penutur Asing，面向外国人的印尼语课程体系）。

## 建议学习方式

生活口语阶段不追求一次记住全部内容。每章优先掌握 5–15 个高频短句，然后通过真实场景、复述和反复测试形成条件反射。

进入 BIPA 后，再系统补充语法、词缀、正式书面语、阅读和写作。
