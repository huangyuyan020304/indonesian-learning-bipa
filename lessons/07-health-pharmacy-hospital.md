# 第7章：身体不舒服、药店、医院与求助

## 学习目标

掌握在印尼生活中遇到身体不适、买药、看医生和紧急求助时最常用的表达。

## 一、常见症状

- sakit = 痛 / 生病
- pusing = 头晕
- demam = 发烧
- batuk = 咳嗽
- pilek = 感冒 / 流鼻涕
- mual = 恶心
- capek = 累
- lemas = 没力气
- panas = 热 / 发热
- dingin = 冷

## 二、表达哪里不舒服

Saya sakit.  
我生病了 / 我不舒服。

Sakit kepala.  
头痛。

Sakit perut.  
肚子痛。

Sakit gigi.  
牙痛。

Sakit tenggorokan.  
喉咙痛。

Saya pusing.  
我头晕。

Saya demam.  
我发烧。

Saya batuk.  
我咳嗽。

Saya mual.  
我恶心。

Saya capek.  
我累。

### 关键结构

`sakit + 身体部位` = 某处疼痛。

口语中也可以省略 Saya，直接说：

Pusing.  
头晕。

Mual.  
恶心。

Capek.  
累。

## 三、药店常用表达

Apotek di mana?  
药店在哪里？

Saya mau obat.  
我要药。

obat = 药

常用组合：

- obat sakit kepala = 头痛药
- obat pilek = 感冒药
- obat batuk = 咳嗽药
- obat demam = 退烧药

Ada obat batuk?  
有咳嗽药吗？

Ada obat demam?  
有退烧药吗？

## 四、吃药频率

Berapa kali sehari?  
一天吃几次？

- berapa = 多少
- kali = 次
- sehari = 一天

Tiga kali sehari.  
一天三次。

Dua kali sehari.  
一天两次。

Sebelum makan.  
饭前。

Sesudah makan.  
饭后。

Minum obat sesudah makan.  
饭后吃药。

注意：印尼语 `minum obat` 字面是“喝药”，实际通常就是“吃药”。

Saya sudah minum obat.  
我已经吃药了。

## 五、医院和医生

Rumah sakit di mana?  
医院在哪里？

Saya mau ke dokter.  
我要去看医生。

Ada dokter?  
有医生吗？

Tolong.  
请帮忙 / 帮帮我。

Tolong saya.  
请帮帮我。

Dia terluka.  
他 / 她受伤了。

Tolong panggil ambulans.  
请叫救护车。

- panggil = 叫 / 呼叫
- ambulans = 救护车

## 六、问诊高频表达

Sakit di mana?  
哪里痛？

Di sini.  
这里。

Sejak kapan?  
从什么时候开始？

Sejak kemarin.  
从昨天开始。

Sejak pagi.  
从早上开始。

Sudah berapa hari?  
已经几天了？

Dua hari.  
两天。

Tiga hari.  
三天。

### 实战对话

Dokter: Sakit di mana?  
医生：哪里痛？

Anda: Sakit perut.  
你：肚子痛。

Dokter: Sejak kapan?  
医生：从什么时候开始？

Anda: Sejak kemarin.  
你：从昨天开始。

Dokter: Mual?  
医生：恶心吗？

Anda: Ya, sedikit.  
你：有一点。

## 七、过敏和药物不适

alergi = 过敏

Saya alergi obat ini.  
我对这个药过敏。

Saya ada alergi.  
我有过敏。

Tidak cocok.  
不适合 / 不合适。

Obat ini tidak cocok.  
这个药不适合我。

## 十、药店实战

Anda: Permisi, ada obat sakit kepala?  
你：请问，有头痛药吗？

Petugas: Ada.  
店员：有。

Anda: Berapa kali sehari?  
你：一天几次？

Petugas: Tiga kali sehari, sesudah makan.  
店员：一天三次，饭后吃。

Anda: Oke, terima kasih.  
你：好的，谢谢。
