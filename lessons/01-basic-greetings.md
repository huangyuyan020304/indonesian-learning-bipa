# 第 1 章：基础问候、自我介绍与发音

目标：先会读、会打招呼、会简单介绍自己。

## 1. 最常用问候

| 印尼语 | 中文 |
|---|---|
| Halo | 你好 |
| Selamat pagi | 早上好 |
| Selamat siang | 中午好 |
| Selamat sore | 下午好 |
| Selamat malam | 晚上好 |
| Terima kasih | 谢谢 |
| Sama-sama | 不客气 |
| Maaf | 对不起 |
| Ya | 是；好的 |
| Tidak | 不；不是 |

## 2. 基础发音

- `a`：类似中文“啊”
- `i`：类似中文“衣”
- `u`：类似中文“乌”
- `c`：类似中文“七”的声母
- `j`：类似中文“吉”的声母
- `g`：通常是硬音

例子：

- makan = 吃
- ini = 这个
- buku = 书
- cari = 寻找
- jalan = 路；走
- pagi = 早晨

## 3. 人称代词

| 印尼语 | 中文 |
|---|---|
| Saya | 我（正式、通用） |
| Aku | 我（熟人之间） |
| Kamu | 你（熟人之间） |
| Anda | 您（正式） |
| Dia | 他／她 |
| Kita | 我们（包括对方） |
| Kami | 我们（不包括对方） |

重点：`Dia` 不区分“他”和“她”；`Kita` 与 `Kami` 的区别很重要。

## 4. 自我介绍

- `Siapa nama kamu?` —— 你叫什么名字？
- `Nama saya Kevin.` —— 我的名字叫 Kevin。
- `Apa kabar?` —— 你好吗？最近怎么样？
- `Baik, terima kasih.` —— 很好，谢谢。
- `Saya orang China.` —— 我是中国人。
- `Saya belajar bahasa Indonesia.` —— 我学习印尼语。

## 5. 一个重要语法特点

印尼语很多简单判断句不需要英语里的 `am / is / are`。

例如：

- `Saya Kevin.` —— 我是 Kevin。
- `Saya orang China.` —— 我是中国人。
