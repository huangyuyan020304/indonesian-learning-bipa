# 第5章：时间、日期与约时间

## 学习目标

掌握问几点、什么时候、今天/明天/昨天、等待、迟到和约时间等高频生活表达。

## 核心词汇

- sekarang = 现在
- nanti = 等会儿 / 之后
- hari ini = 今天
- besok = 明天
- kemarin = 昨天
- jam = 点钟 / 小时
- kapan = 什么时候
- pagi = 早上
- siang = 中午 / 白天
- sore = 下午
- malam = 晚上
- sebentar = 一会儿
- tunggu = 等
- ketemu = 见面（口语）
- telat = 迟到
- mulai = 开始
- selesai = 结束 / 完成
- kerja = 工作
- libur = 放假 / 休息

## 重点句型

### 1. 问时间

**Sekarang jam berapa?** 现在几点？

**Jam tiga.** 3点。

**Jam tujuh pagi.** 早上7点。

**Jam dua siang.** 下午2点。

**Jam enam sore.** 傍晚6点。

**Jam sembilan malam.** 晚上9点。

### 2. 问什么时候

**Kapan?** 什么时候？

**Kapan pergi?** 什么时候走？

**Kapan datang?** 什么时候来？

回答可以很短：

- **Besok.** 明天。
- **Nanti.** 等会儿。
- **Sekarang.** 现在。
- **Malam ini.** 今晚。

### 3. 问几点做某事

**Jam berapa makan?** 几点吃饭？

**Pergi jam berapa?** 几点走？

**Datang jam berapa?** 几点来？

### 4. 等一下

**Sebentar ya.** 等一下。

**Tunggu sebentar.** 稍等一下。

**Nanti saja.** 晚点吧。

**Besok saja.** 明天吧。

### 5. 今天、明天、昨天

**Hari ini kerja?** 今天工作吗？

**Besok libur?** 明天休息吗？

**Kemarin kerja.** 昨天工作了。

### 6. 约时间

**Ketemu jam berapa?** 几点见？

**Besok ketemu jam berapa?** 明天几点见？

**Jam delapan bisa?** 8点可以吗？

**Nggak bisa.** 不行。

**Jam sembilan bisa?** 9点可以吗？

### 7. 迟到

**Saya telat.** 我迟到了。

**Maaf, saya telat.** 对不起，我迟到了。

## 实战对话

A: **Besok kerja?**  明天上班吗？

B: **Ya.**  对。

A: **Jam berapa mulai?**  几点开始？

B: **Jam delapan pagi.**  早上8点。

A: **Selesai jam berapa?**  几点结束？

B: **Jam lima sore.**  下午5点。
