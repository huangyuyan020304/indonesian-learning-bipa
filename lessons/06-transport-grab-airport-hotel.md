# 第6章：交通、Grab、机场和酒店

## 学习目标

掌握在印尼出行时最实用的表达：叫车、告诉司机位置、说方向、机场问路、酒店入住和处理常见问题。

## 一、核心词汇

- jalan = 路 / 走
- pergi = 去
- datang = 来
- naik = 上车 / 乘坐
- turun = 下车
- mobil = 汽车
- motor = 摩托车
- bandara = 机场
- hotel = 酒店
- alamat = 地址
- kiri = 左
- kanan = 右
- lurus = 直走
- dekat = 近
- jauh = 远
- depan = 前面
- belakang = 后面
- sampai = 到达
- tunggu = 等
- terminal = 航站楼 / 车站
- bagasi = 行李
- kamar = 房间
- masalah = 问题

## 二、打车和 Grab

**Saya mau ke sini.**
我要去这里。

**Ke sini, ya.**
去这里。

**Saya mau ke hotel.**
我要去酒店。

**Saya mau ke bandara.**
我要去机场。

**Saya di sini.**
我在这里。

**Saya di depan hotel.**
我在酒店前面。

**Saya di belakang hotel.**
我在酒店后面。

**Saya tunggu di sini.**
我在这里等。

## 三、到达、停车、下车

**Sudah sampai?**
到了吗？

**Sudah.**
到了 / 已经。

**Belum.**
还没。

**Berhenti di sini.**
在这里停车。

**Turun di sini.**
我在这里下车。

**Sedikit lagi.**
再往前一点。

## 四、方向

**Kiri.**
左边。

**Kanan.**
右边。

**Lurus.**
直走。

**Lurus saja.**
一直走就行。

**Bukan di sini.**
不是这里。

### tidak 和 bukan

**tidak** 常用来否定动作或状态：

- Tidak tahu. = 不知道。
- Tidak bisa. = 不可以 / 不会。

**bukan** 常用来表示“不是某个人、东西、地点”：

- Bukan ini. = 不是这个。
- Bukan di sini. = 不是这里。

## 五、机场

**Permisi.**
打扰一下 / 借过。

**Bandara di mana?**
机场在哪里？

**Terminal berapa?**
几号航站楼？

**Gate berapa?**
几号登机口？

**Check-in di mana?**
在哪里办理值机？

**Bagasi di mana?**
行李在哪里？

**Permisi, toilet di mana?**
请问，厕所在哪里？

## 六、酒店

**Saya mau check-in.**
我要办理入住。

**Nama saya Kevin.**
我的名字叫 Kevin。

**Saya sudah pesan.**
我已经预订了。

**Saya sudah pesan kamar.**
我已经订房了。

**Kamar saya di mana?**
我的房间在哪里？

**Ada Wi-Fi?**
有 Wi-Fi 吗？

**Password Wi-Fi apa?**
Wi-Fi 密码是什么？

**Ada masalah.**
有问题。

**AC nggak dingin.**
空调不冷。

**Air panas nggak ada.**
没有热水。

## 八、Grab 实战对话

司机：**Di mana?**
在哪里？

你：**Saya di depan hotel.**
我在酒店前面。

司机：**Sudah siap?**
准备好了吗？

你：**Sudah.**
好了。

上车后：**Saya mau ke bandara.**
我要去机场。

快到时：**Sedikit lagi.**
再往前一点。

最后：**Berhenti di sini.**
在这里停车。
